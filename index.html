Grouped as they're used in the wild: entrances, exits, attention‑seekers, ambient loops and a few UI specials. Click ↻ to replay any one on its own — the rest keep cycling every 3.4s.

A timing function is a curve plotting output progress (y) against time elapsed (x). Drag the two control points below to build any cubic-bezier() — the ball moves exactly as the curve dictates, driven by real CSS.

  • P0 (0, 0) — start, fixed
  • P1 drag — steers the early motion
  • P2 drag — steers the late motion
  • P3 (1, 1) — end, fixed
  • x = time 0→1 · y = progress (can overshoot below 0 or above 1)
cubic-bezier(0.25, 0.10, 0.25, 1.00)

Native CSS keywords

These resolve to exact cubic-bezier() (or steps()) values per the CSS spec — five of them are the preset buttons in the plotter above.

Named easing functions

The 30 reference curves popularized by easings.net. They're polynomial/trig/exponential formulas rather than CSS keywords, so each one is sampled into a native linear() timing function to drive its dot.
